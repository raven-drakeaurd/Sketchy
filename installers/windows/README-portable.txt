Sketchy - portable Windows app
==============================

1. Keep this whole folder together (Sketchy.exe needs the files next to it).
2. Double-click Sketchy.exe to start.

The first time, Windows SmartScreen may say "Windows protected your PC" because
the app is not code-signed. Click "More info", then "Run anyway".

Files
- File > Save / Save As saves .skw model files anywhere on your PC.
- File > Open opens .skw files (or .json models exported from the web version).
- File > Import STL brings in STL meshes; you choose the units the file uses.
- File > Export saves STL (3D printing), OBJ (other 3D programs) or a PNG.
- You can also drag a .skw or .stl file onto the window.

Your current model is also autosaved, and the Welcome screen offers
"Continue last model" the next time you start.
